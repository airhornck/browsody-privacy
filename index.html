Browsody 隐私政策

生效日期： 2026 年 7 月 13 日

最后更新： 2026 年 10 月 24 日

1. 引言

Browsody（"我们"、"本扩展"）是一款 AI 驱动的个人浏览年鉴工具。我们高度重视您的隐私。本扩展采用本地优先（local-first）架构：您的浏览数据默认只存储在您的浏览器本地，我们不会收集、上传或出售您的个人数据。

本隐私政策解释本扩展如何处理您的信息，以及您对自己的数据拥有哪些权利。

2. 我们收集哪些数据

Browsody 仅在您的浏览器本地收集和处理以下信息：

  • 浏览记录：您访问的网页 URL、页面标题、域名、访问时长、访问时间
  • 分类统计：基于 URL/标题自动归类的时间分布（如工作、学习、娱乐等）
  • 每日统计：浏览总时长、热门站点、专注度评分等汇总数据
  • AI 洞察：由 AI 生成的每日浏览总结文本
  • 用户设置：分类规则、忽略域名、数据保留期限、AI 模型偏好、您自行配置的 API Key（仅存储在本地）等

我们不会收集：

  • 您的姓名、邮箱、账号信息
  • 网页内容、密码、表单输入、Cookie
  • 付款信息

3. 数据存储位置

所有数据均存储在您的浏览器 IndexedDB 和 chrome.storage.local 中，不会上传到我们的服务器。

您随时可以在扩展的"隐私"或"设置"页面：

  • 导出所有数据为 JSON 文件
  • 一键彻底删除所有本地数据

4. AI 功能与数据去向

Browsody 按以下优先级生成 AI 洞察：

4.1 本地 Gemini Nano（默认）

在支持的 Chrome 浏览器（Chrome 148+）中，AI 模型直接在您的设备上运行，任何数据都不会离开您的电脑。

4.2 用户自有 API Key（BYOK）

您可以在设置中配置自己的 DeepSeek API Key。此时，当日浏览的脱敏聚合摘要（总时长、站点域名、各分类时长，不含完整 URL 与页面内容）会从您的浏览器直接发送至 DeepSeek API 以生成总结，传输过程遵循 DeepSeek 的隐私政策。Browsody 开发者不运营任何 AI 服务、不接触您的数据与 API Key。

4.3 本地模板兜底

无可用 AI 模型时，扩展在本地生成纯模板化的统计摘要，不发生任何网络传输。

5. 权限说明

本扩展请求以下权限，均用于实现核心功能：

权限 用途
tabs 监听活动标签页变化，计算访问时长（不读取页面内容、不注入脚本）
storage 存储用户设置与试用状态
unlimitedStorage 在本地 IndexedDB 持久化浏览记录与统计数据（数据仅存本地）
idle 检测用户空闲/锁定状态，暂停计时，避免挂机时间被计入
alarms 定时生成每日洞察与清理过期数据
host_permissions（仅 api.deepseek.com） 仅当您主动配置自己的 DeepSeek API Key 并选择云端生成时，向该端点发送脱敏聚合摘要

6. 数据分享

我们不会向任何第三方出售、出租或共享您的个人数据。仅在以下情形发生数据传输：

  • 您主动启用云端 AI（BYOK）时，脱敏聚合摘要直接传输至您自行配置的 AI 服务商；
  • 您主动点击"导出数据"时，数据以 JSON/Markdown 文件保存到您的本地设备。

7. 您的权利

根据 GDPR 等数据保护法规，您拥有以下权利：

  • 知情权：本政策已说明全部数据处理活动；
  • 访问权：随时在扩展内查看自己的全部数据；
  • 导出权：一键导出 JSON 格式的完整数据；
  • 删除权：一键清除所有本地数据；
  • 撤回同意权：卸载扩展即可停止所有数据收集。

8. 未成年人

本扩展不面向 13 岁以下未成年人。如果您发现未成年人向我们提供了个人信息，请联系我们删除。

9. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在扩展商店页面和本文件中公布。
